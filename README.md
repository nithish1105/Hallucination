# Hallucination
1. Introduction
Large Language Models (LLMs) such as ChatGPT, Llama, Gemini, and Claude are capable of
generating human-like conversations. However, these models sometimes generate information that is
false, misleading, or unsupported by facts. This problem is called hallucination.
The proposed project develops a web application that detects hallucinations while a user is chatting
with an AI assistant (Maya) or interacting through live video communication. Instead of directly
trusting the LLM response, the application verifies every important statement using trusted knowledge
sources before presenting it to the user. The application also provides a confidence score, allowing
users to understand how reliable the generated response is.
2. Problem Statement
Large Language Models generate responses based on learned patterns rather than checking
whether the information is true. As a result, users may receive incorrect information without knowing
that it is inaccurate.
There is currently no simple system that simultaneously:
• Detects hallucinations in AI conversations
• Verifies generated information using trusted knowledge
• Provides supporting evidence
• Calculates a confidence score
• Works during real-time chatting or video conversations
This project addresses these limitations.
3. Objectives
The main objectives are:
• Detect hallucinated responses generated by LLMs
• Verify responses using Retrieval-Augmented Generation (RAG)
• Compare AI responses with trusted sources
• Calculate a confidence score
• Display verified information to the user
• Improve trust in AI conversations
4. Proposed System
The proposed application works as an intelligent verification layer between the user and the Large
Language Model. Instead of directly displaying the LLM response, the system performs multiple
verification steps before presenting the final answer.

6. Working Principle
Step 1
The user asks a question by chatting with Maya or speaking through live video.
Step 2
If the user is speaking, Speech Recognition converts speech into text.
Step 3
The text is sent to the LLM.
Example
User: Who invented Python?
LLM: Guido van Rossum invented Python.
This is only the initial response.
Step 4
The Retrieval Module searches trusted documents.
Datasets used: Wikipedia, FEVER, HaluEval.
The system retrieves related information.
Step 5
The Verification Module checks whether the retrieved information supports the generated response.
Possible outputs: Supported / Refuted / Not Enough Information.
Step 6
Hallucination Detection — If the response is not supported, a hallucination is detected.
Step 7
Confidence Estimation — The confidence score is calculated using Semantic Similarity, Retrieval
Score, and Verification Probability.
Step 8
The final output contains: Verified Answer, Confidence Score, Evidence, Hallucination Status.
7. Modules
Module 1 – User Interface
Provides: Chat Screen, Maya AI Assistant, Live Video Interface
Module 2 – Large Language Model
Generates the initial AI response. Possible models: GPT, Llama 3, Mistral.
Module 3 – Retrieval-Augmented Generation
Searches trusted knowledge using FAISS and Sentence Transformers. Knowledge sources:
Wikipedia and Custom Documents.
Module 4 – Verification Module
Uses DeBERTa and RoBERTa to compare the generated response with retrieved evidence.
Module 5 – Hallucination Detection
Checks whether the generated response matches retrieved evidence. If not, a hallucination is
detected.
Module 6 – Confidence Estimation
Calculates confidence using Semantic Similarity, Retrieval Score, and NLI Probability.

11. Confidence Formula
The confidence score is calculated using the following weighted formula:
Confidence = 0.4 × Semantic Similarity
+ 0.3 × Retrieval Score
+ 0.2 × Verification Score
+ 0.1 × LLM Confidence
A higher confidence score indicates that the generated response is more likely to be factually correct.

16. Conclusion
The proposed project provides a practical solution for improving the trustworthiness of Large
Language Models. During conversations with the AI assistant Maya or through live video, the system
does not rely only on the initial AI response.
Instead, it retrieves information from trusted sources, verifies the response using Natural Language
Inference models, detects hallucinations, and calculates a confidence score before presenting the
final answer.
By integrating Retrieval-Augmented Generation (RAG), DeBERTa/RoBERTa verification, and
confidence estimation, the application helps users receive more reliable and explainable responses.
This makes the system suitable for real-world applications where factual accuracy is essential, such
as education, healthcare, finance, legal services, and enterprise knowledge management.
